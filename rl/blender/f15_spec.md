# F-15C 형상 사양 (모델링 기준표)

좌표: three.js 기준 (glTF 출력 후). X = 오른쪽(스팬), Y = 위, Z = 뒤쪽(+). **기수 끝 Z = -10.05, 노즐 끝 Z = +9.35** (전장 19.40).
아래 `s` = 기수 끝에서 뒤로 잰 거리(m) → Z = -10.05 + s. 좌우 대칭(X 는 ± 로 표기).
Blender 에서는 -Y 가 앞쪽이 되도록 만들고 glTF 내보내기(+Y up)로 위 좌표가 되게 하라. 기존 game.js 1인칭 눈 위치 = (0, 1.12, -4.75) ⇒ s = 5.30.

치수는 공개 3면도 기반 근사치다. 실루엣 비율이 우선.

## 2. 흡입구 (좌우 각각)
- 박스 바깥면 x = ±2.10, 안쪽면 x = ±1.10, 동체와의 틈(분리판 자리) x = ±0.70 ~ ±1.10 사이에 얇은 판 하나.
- 입구 면: 윗 립 s = 5.4, 아래 립 s = 6.1 (위가 앞으로 나온 사선).
- 입구 단면: 높이 y -0.75 ~ +0.55, **사각형**(모서리 반경 0.05~0.08). 윗면은 바깥쪽이 0.08 낮게 기울어짐.
- 입구 안쪽은 어두운 램프면(위에서 아래로 기울어짐), 깊이 1 m 이상.
- 덕트 바깥면은 s 5.6 → 13 까지 거의 수직 평면, 윗모서리 반경 0.15 로 동체 윗면과 연결. 주익 앞전과 만나는 부분에 필렛.

## 3. 캐노피
- 윈드실드 아래 앞끝 s = 3.4 (윗면 y 0.62), 윈드실드는 약 35° 로 서서 s = 4.2 에서 꼭대기 근처.
- 버블 최고점 s = 4.9, y = 1.42 (동체 윗면 위 약 0.72). 폭 최대 0.95.
- 캐노피 뒤 끝 s = 7.2, 뒤쪽 등 페어링으로 s = 9.5 까지 완만하게 윗면(0.80)에 수렴.
- 프레임: 윈드실드 뒤 아치 1개(s 4.25), 캐노피 뒤 끝 프레임. 중심선 앞뒤 프레임 없음.

## 4. 주익 (고익, 좌우)
- 위치: 동체 윗면 바로 아래, 뿌리 y ≈ 0.40. 하반각 약 -1°.
- 뿌리(x = ±2.10): 앞전 s = 8.6, 뒷전 s = 13.6 (시위 5.0).
- 끝(x = ±6.53): 앞전 s = 13.1, 뒷전 s = 14.6 (시위 1.5). 앞전 후퇴각 ≈ 45°, 뒷전은 거의 직선(약간 전진).
- 끝단은 사선 클립(앞쪽 모서리 잘림 0.4 m).
- 두께: 뿌리 6%(약 0.30 m), 끝 3%(약 0.045 m). 앞전 둥글게, 뒷전 날카롭게.
- 조종면: 에일러론 x ±4.4~6.2, 플랩 x ±2.2~4.3, 뒷전에서 시위 25%. 틈은 3 cm 선.
